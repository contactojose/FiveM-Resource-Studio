FIVEM RESOURCE STUDIO — BETA 0.2.0

Esta entrega mejora el módulo de análisis inteligente y el informe de recuperación.

NOVEDADES
- Inventario de archivos de ZIP y carpetas.
- Identificación de marcadores/archivos con firma o extensión FXAP.
- Clasificación separada de Lua, texto, assets binarios y formatos no clasificados.
- Lectura de patrones escrow_ignore declarados en fxmanifest.lua / __resource.lua y anotación de coincidencias.
- Barra de progreso por etapas con estado real del análisis.
- Informe detallado exportable en JSON.
- Inspección no destructiva: conserva los originales y no elimina archivos.

IMPORTANTE SOBRE CFX ASSET ESCROW
Esta versión NO descifra ni elude CFX Asset Escrow. La presencia de FXAP o una extensión compatible no prueba por sí sola qué archivo está cifrado. El análisis es estático y orientativo. Para recuperar contenido protegido se requiere una fuente o mecanismo autorizado del creador/proveedor. No se simula una recuperación ni se elimina FXAP automáticamente.

COMPILAR INSTALADOR WINDOWS
El workflow de GitHub Actions genera el instalador Windows x64. En GitHub: Actions > Construir instaladores FiveM Resource Studio > Run workflow. El artefacto se descarga desde la ejecución terminada. El usuario final no necesita Python.

LIMITACIONES
- La compilación macOS requiere runners compatibles; los DMG de CI no están firmados ni notarizados.
- Los diagnósticos estáticos no garantizan ejecución correcta dentro de FiveM.
- Los mapas binarios no se editan directamente.

PRUEBAS
Usar copias de recursos. Validar apertura, inventario, progreso, informe JSON y exportación en un servidor de pruebas.
